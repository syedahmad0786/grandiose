THE LAST LIGHT

Closing the final tab should feel like a funeral, a roast, or awards night. The save-opera still exists. It is no longer the point. When one tab remains, the extension whispers. When a window dies, the ceremony plays on whatever is left. Browsers will not overlay the void after the last window is gone. We work with that.
